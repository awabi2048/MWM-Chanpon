# 修正期間と観光用シミュレーションの画面仕様

## 管理画面

`/chanpon-mwm` の既存45枠画面を維持し、左下の36番スロットに修正期間用バイパスを配置します。背景と他の項目の位置は維持します。固定された項目名と説明、現在の有効・無効、実行可能な切替操作を共通GUI部品に渡し、状態は色と文字で表します。管理者が有効にすると全体の建築停止を解除し、無効にすると停止を有効にします。

## ワールド設定画面

既存の保護中・通常時の画面サイズ、背景、設定項目、情報順、戻る経路は維持します。修正期間中は左上の0番スロットに観光用シミュレーションを配置します。固定名、説明、状態、切替操作は共通GUI部品へ渡します。オーナー、モデレーター、メンバー、管理者が使用でき、シミュレーション中にも解除できます。

この配置は対象ワールドの提出・完成後の保護と観光モードを試し、同じ画面から確実に解除できるよう設けます。ボタンの位置・素材・状態・操作は維持し、説明に観光モードの適用を追加します。対象ワールド内では、通常の管理者例外を除きゲームモードと観光専用操作制限も適用します。
