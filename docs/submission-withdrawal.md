# 提出取り下げの画面・状態契約

- オーナーは既存のワールド設定画面下部にある提出項目から確認画面へ進みます。保護時の短縮画面の寸法、背景、公開設定・通知設定の配置は維持します。提出済み項目だけ操作可能にし、締切済みと完成済みは実行できません。
- 管理者は既存の提出状況一覧のワールドをシフト左クリックして確認画面へ進みます。統合版ではワールド項目を選択すると移動と取り下げの選択フォームを表示します。既存の一覧配置、通常クリックによる移動、完成マーク操作、本番用設定解除を維持します。
- 確認画面は既存のConfirmation共通レイアウトを使用し、取り下げと公開範囲の復元について説明します。表示後に締切・権限・状態が変化した場合も確定時に再確認します。
- 未提出への変更と履歴の追加は同じワールドデータへの単一保存で行います。提出前の公開範囲は提出ごとに記録し、取り下げ時に公開中の場合だけ復元します。既存提出に記録がない場合は非公開へ戻します。ほかの設定と提出後に選択した非公開・開発中は維持します。
- 提出による建築・ツール権限のロックは再同期し、別の理由による保護は維持します。
